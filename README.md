# 📌 JavaScript DOM Practice

This repository contains my hands-on practice of **DOM (Document Object Model)** concepts in JavaScript.
It includes multiple examples and mini-tasks to understand how JavaScript interacts with web pages.

---

## 🚀 About the Project

The **DOM** allows JavaScript to access and manipulate HTML and CSS dynamically.
In this project, I practiced:

* Selecting elements
* Modifying content
* Styling elements
* Handling events
* Creating and deleting elements
